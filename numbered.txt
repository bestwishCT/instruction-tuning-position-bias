11: 5 Is More Context Is Always Better?
12: A Case Study With Open-Domain QA
13: Our results indicate that prompting lan-
14: guage models with longer input contexts is a
15: trade-off—providing the language model with
16: more information may help it perform the
17: downstream task, but it also increases the amount
18: of content that the model must reason over, po-
19: tentially decreasing accuracy. Even if a language
20: model can take in 16K tokens, is it actually
21: beneficial to provide 16K tokens of context? The
22: answer to this question is ultimately downstream
23: task-specific since it depends on the marginal
24: value of the added context and the model’s ability
25: to effectively use long input contexts, but we
26: perform a case study with open-domain question
27: answering on NaturalQuestions-Open to better
28: understand this trade-off in existing language
29: models.
30: We use language models in a standard
31: retriever-reader setup. A retrieval system (Con-
32: triever, fine-tuned on MS-MARCO) takes an input
33: query from NaturalQuestions-Open and returns

72: 6.1 Long-Context Language Models
73: There is much prior work in designing perfor-

75: Transformers in the context length. Many lines of
76: work pursue Transformer variants with attention
77: modifications like recurrence (Dai et al., 2019),

79: intensive approximations (Beltagy et al., 2020;
80: Zaheer et al., 2020), or low-rank approximations
